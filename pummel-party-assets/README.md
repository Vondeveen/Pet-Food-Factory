# Pummel Party Mod Editor assets

3D models from the web game, exported as `.obj` for the Pummel Party Mod Editor
(**Asset Browser → Import Asset**).

OBJ files carry shape only, no colours. After importing, give each one a material in the
editor using these colours:

| File | Suggested colour |
| --- | --- |
| `heart.obj` | dark red `#8f0d1c` |
| `brain.obj` | pink `#e6939c` |
| `eyeball.obj` | white `#f7f1e8` (iris and pupil are part of the same mesh) |
| `guts.obj` | salmon `#d98572` |
| `golden_heart.obj` | gold `#ffd23f` (bonus organ) |
| `bin.obj` | heart bin `#e63946`, brain bin `#ff8fab`, eye bin `#48cae4`, guts bin `#f4a261` |
| `grinder.obj` | dark grey `#495057` |
| `conveyor_belt.obj` | dark grey `#2e2e38` |

Units match the web game: an organ is about 1 unit across, a bin is about 1.6 units wide,
and the conveyor is 15 units long. Scale them in the editor so they look right next to the
Pummel Party characters.
